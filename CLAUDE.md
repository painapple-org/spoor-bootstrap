# CLAUDE.md

This is a thin pointer file, not this repo's actual instructions.

Read [`AGENTS.md`](./AGENTS.md) for how this repo wants to be worked on and
operated — the first-boot interview, the self-provisioning shopping-list
framing, everything. Read [`skills/`](./skills/README.md) for this repo's
actual skill content — that file's "Current skills" list is the one
enumeration of what's there and which of them are still stubs, so start
from it rather than from a skill named here.

Why this file doesn't just restate that content: this repo is meant to
work the same way regardless of which agentic harness runs it (Claude
Code, OpenCode, Codex CLI, or another). Duplicating `AGENTS.md`'s content
into a Claude-Code-specific file would give it two homes that could drift
out of sync with each other — see `AGENTS.md` itself, which is the one
place this repo's behavior is actually described.
